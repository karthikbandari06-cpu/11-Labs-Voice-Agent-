# 11-Labs-Voice-Agent-
A multilingual doctor appointment booking voice agent built with **ElevenLabs Conversational AI (ElevenAgents)** and React. It conducts real-time voice interactions across English, Telugu, and Hindi, automatically collecting patient details, checking doctor availability, scheduling appointments, and logging full call transcripts and analytics.
